# Python Data Structures Exercises

Solutions to six exercises on Python's built-in data structures: lists, tuples, dictionaries and sets.

| # | Exercise |
|---|----------|
| 1 | Multiply all the items in a list |
| 2 | Sort a list of tuples by the last element |
| 3 | Combine two dictionaries, adding values for common keys |
| 4 | Build a dictionary of `{i: i*i}` for 1..n |
| 5 | Sort tuples by their float element |
| 6 | Create a set, iterate over it, add and remove items |

## Run

```bash
python python_exercises.py
```
